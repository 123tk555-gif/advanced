# Tri-Tri 画面一覧

> 要件定義書の機能を、どの画面で行うかの一覧。細かい項目・文言は画面仕様定義書で決める。

## 画面と URL
| ID | 画面 | URL | 見られる人 | 主な内容 |
|---|---|---|---|---|
| S01 | ログイン | `/login` | 誰でも | メール・パスワード、会員登録・パスワード再設定へのリンク |
| S02 | 会員登録 | `/signup` | 誰でも | メール・パスワード・表示名 |
| S03 | 確認コード入力 | `/signup/confirm` | 誰でも | メールで届いた確認コード、再送 |
| S04 | パスワード再設定 | `/password-reset` | 誰でも | メール入力 → 確認コードと新しいパスワード |
| S05 | 旅の一覧(ホーム) | `/trips` | 会員 | 参加中の旅(日付の近い順)、「旅を作る」ボタン |
| S06 | 旅の作成 | `/trips/new` | 会員 | タイトル・開始日・終了日・行き先 |
| S07 | 旅の画面 | `/trips/:tripId` | メンバー | 4 つのタブ(下記)と、今見ているメンバーの表示 |
| S08 | 招待への参加申請 | `/join/:inviteToken` | 会員(未ログインならログイン後に戻る) | 旅の名前・メンバー数だけを表示。「参加を申請する」ボタン。申請後は「オーナーの承認待ち」(5 秒ごとに確かめ、承認されたら自動で旅の画面へ移る)。すでにメンバーなら、開いたらすぐ旅の画面へ |
| S09 | 旅の設定 | `/trips/:tripId/settings` | メンバー(操作はオーナーのみのものあり) | 下記 |
| S10 | 公開しおり | `/p/:publicToken` | 誰でも | 旅程・地図・経路・メンバーの表示名(読み取り専用) |
| S11 | アカウント設定 | `/settings` | 会員 | 表示名の変更、ログアウト、退会 |
| S12 | 見つかりません | (該当しない URL すべて) | 誰でも | 旅が無い・メンバーでない・リンクが止められた場合もここ |

## S07 旅の画面のタブ
| タブ | URL | 内容 |
|---|---|---|
| 旅程 | `/trips/:tripId`(既定) | 日ごとの予定の一覧と地図。PC は左に一覧・右に地図、スマートフォンは「一覧/地図」の切り替え |
| 候補 | `?tab=ideas` | 行きたい場所の候補と票数、投票、採用して旅程に入れる |
| 割り勘 | `?tab=money` | 支出の一覧と追加、精算(誰が誰にいくら) |
| メンバー | `?tab=members` | メンバーの一覧(オーナーの印)、招待リンクのコピーと有効期限。オーナーには**参加申請の一覧と承認・却下ボタン**(未処理の件数をタブにも表示) |

### 旅程タブの中の操作
- **予定の追加・編集**(ダイアログ): 時刻・タイトル・場所(地名検索で候補が出る)・メモ。保存のときに他の人が先に変えていたら、**衝突ダイアログ**で「自分の内容/相手の内容」を見せて選ばせる
- **予定の詳細**(一覧の行を開く): メモ、Google マップで開く、コメントの一覧と投稿
- **並べ替え**: ドラッグと、キーボードでも動かせる「上へ/下へ/別の日へ」ボタン
- **地図**: その日の予定のピンと経路、区間ごとの移動時間。移動手段(車・徒歩・公共交通)の切り替え
- 他の人が編集中の予定には「○○さんが編集中」を表示

## S09 旅の設定
| 項目 | オーナー | メンバー |
|---|---|---|
| 旅の情報(タイトル・日付・行き先)の変更 | ○ | 見るだけ |
| 招待リンクの発行し直し・停止 | ○ | — |
| 参加申請の承認・却下(メンバータブ) | ○ | — |
| 公開リンクの発行・停止 | ○ | 見るだけ |
| メンバーを外す | ○ | — |
| オーナーを引き継ぐ | ○ | — |
| 旅から抜ける | 引き継いでから | ○ |
| 旅の削除 | ○ | — |

## 画面の流れ
```
S01 ログイン ──→ S05 旅の一覧 ──→ S07 旅の画面 ──→ S09 旅の設定
   │  ↑              │                 ↑
   ↓  │              ↓                 │
S02 登録 → S03 確認  S06 旅の作成 ──────┘

招待リンク → S08 参加申請(未ログインなら S01 → 戻る)→ オーナーが承認 → S07
公開リンク → S10 公開しおり(ログイン不要)
```
