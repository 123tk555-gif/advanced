# Tri-Tri 画面一覧

> 要件定義書の機能を、どの画面で行うかの一覧。細かい項目・文言は画面仕様定義書で決める。

## S07 旅の画面のタブ
| タブ | URL | 内容 |
|---|---|---|
| 旅程 | `/trips/:tripId`(既定) | 日ごとの予定の一覧と地図。PC は左に一覧・右に地図、スマートフォンは「一覧/地図」の切り替え |
| 候補 | `?tab=ideas` | 行きたい場所の候補と票数、投票、採用して旅程に入れる |
| 割り勘 | `?tab=money` | 支出の一覧と追加、精算(誰が誰にいくら) |
| メンバー | `?tab=members` | メンバーの一覧(オーナーの印)、招待リンクのコピーと有効期限。オーナーには**参加申請の一覧と承認・却下ボタン**(未処理の件数をタブにも表示) |

### 旅程タブの中の操作
- **予定の追加・編集**(ダイアログ): 時刻・タイトル・場所(地名検索で候補が出る)・メモ。保存のときに他の人が先に変えていたら、**衝突ダイアログ**で「自分の内容/相手の内容」を見せて選ばせる
- **予定の詳細**(一覧の行を開く): メモ、Google マップで開く、コメントの一覧と投稿
- **並べ替え**: ドラッグと、キーボードでも動かせる「上へ/下へ/別の日へ」ボタン
- **地図**: その日の予定の番号つきピンと経路、区間ごとの移動時間。移動手段(車・徒歩・公共交通)の切り替え。公共交通の経路は破線で描く
  - Google マップの API キーがあれば本物の地図と経路検索の時間、なければ位置関係だけの簡略図と、徒歩・車は直線距離からの目安(自動テスト・CI はこちら)。設定は [Googleマップの設定.md](Googleマップの設定.md)
  - 移動時間は、地図で選んでいる日だけ一覧にも出す(経路検索の利用回数を抑えるため)
  - 経路が見つからない・取得に失敗した区間は、時間も線も出さず「Google マップで調べる」リンクを出す(日本の公共交通はいつもこちら)
  - 位置を取得できなかった場所は、地図の下に番号と表示名で知らせる。ほかのピンの番号はずらさない
  - Google から取った候補・移動時間には「Google Maps」の帰属表示を付ける
- **場所の入力**(予定・候補で共通): 2 文字以上入れて入力が止まると候補が出る。↑↓ で選び Enter で決める。選ぶと欄が「しおりに出す表示名」に変わる(最初は入力した文字のまま。自由に変えられる)。候補から選ばずに文字だけ入れたときは保存しない
  - 選んだ直後は「選んだ場所: (候補の名前)」を画面にだけ出し(保存しない)、表示名を全選択にする。そのまま打てば書き直せる。後から編集で開いたときは出ない
  - 候補は最大 10 件: ふつうの候補(最大 5 件)+ 駅・バス停・路面電車・港・空港(最大 5 件)。乗り物には種類を文字で付ける
  - その旅に登録済みの場所があれば、その近く(50km 以内)を優先する。基準は、その日の最後の場所(無ければ近い日の場所。候補タブは旅の最初の方の場所)。遠くの場所も除かない
- 他の人が編集中の予定には、一覧とその予定のダイアログに「○○さんが編集中」を文字で表示(編集は止めない。自分の分は自分には出さない)

### 旅の画面のリアルタイム更新(4 つのタブ共通)
- 変更の合図が届いたら読み直す。入力中の文字・カーソル・フォーカス・動かした地図の位置は保つ
- ダイアログを開いている間・日本語の変換中は、終わるまで読み直しを待つ
- 割り勘の入力中にメンバーが増えたら、全員を選んでいるときだけ「分け合う人」に加える
- ほかの人の変更による読み直しは、前回から 2 秒あけ、0.5 秒の幅でずらす(大勢の旅で DB の読み取りを抑える)。自分の変更はすぐ読む
- 切れたら「再接続中」と出し、自動でつなぎ直す。その間は 15 秒ごとに読み直す(つながっていても 2 分に 1 回)
- タブを 1 分以上隠すと「今見ている人」から外れ、戻るとつなぎ直す
- 外された・抜けた・退会・旅の削除のときは、しおりを画面から消す

## S09 旅の設定
| 項目 | オーナー | メンバー |
|---|---|---|
| 旅の情報(タイトル・日付・行き先)の変更 | ○ | 見るだけ |
| 招待リンクの発行し直し・停止 | ○ | — |
| 参加申請の承認・却下(メンバータブ) | ○ | — |
| 公開リンクの発行・停止 | ○ | 見るだけ |
| メンバーを外す | ○ | — |
| オーナーを引き継ぐ | ○ | — |
| 旅から抜ける | 引き継いでから | ○ |
| 旅の削除 | ○ | — |

## 画面の流れ
```
S01 ログイン ──→ S05 旅の一覧 ──→ S07 旅の画面 ──→ S09 旅の設定
   │  ↑              │                 ↑
   ↓  │              ↓                 │
S02 登録 → S03 確認  S06 旅の作成 ──────┘

招待リンク → S08 参加申請(未ログインなら S01 → 戻る)→ オーナーが承認 → S07
公開リンク → S10 公開しおり(ログイン不要)
```
